# Mo1

Mo1 هو مشروع يهدف إلى إنشاء شات ذكاء اصطناعي يلعب دور موظف المبيعات. يقدم هذا الشات إجابات ودية ومفيدة للعملاء المحتملين، ويمكن تشغيله محلياً باستخدام بايثون ومكتبة Transformers.

## المتطلبات

- Python 3.8 أو أحدث
- مكتبة `transformers` من Hugging Face

يمكن تثبيت المتطلبات عبر:

```bash
pip install transformers
```

## الاستخدام

بعد تثبيت المتطلبات، شغّل السكربت:

```bash
python sales_chatbot.py
```

سيتم تحميل نموذج لغوي صغير ويبدأ الشات باستقبال أسئلة المستخدم من الطرفية والرد عليها.
